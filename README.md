# Website IMKK — Usability Engineering

Website pembelajaran dan media presentasi mengenai Usability Engineering dalam mata kuliah Interaksi Manusia dan Komputer.

Website ini menggunakan HTML, CSS, dan JavaScript statis. Three.js dimuat melalui CDN; tidak diperlukan proses build atau backend untuk menjalankannya.

## Menjalankan secara lokal

Buka `index.html` melalui server web lokal, misalnya Apache di Laragon. Halaman ini menggunakan JavaScript ES modules, sehingga akses melalui server HTTP/HTTPS disarankan daripada membuka file langsung dengan `file://`.
